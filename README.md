### Cyber Risk Engine

A cybersecurity application designed for IT asset
inventory, vulnerability management and risk analysis.

**Core features:**

- IT asset management
- Vulnerability inventory
- NVD API integration
- CVE, CWE and CVSS analysis
- Mathematical risk modeling
- SQLite database persistence
- REST API with FastAPI
- Docker containerization

**Technology stack:**

`Python` `FastAPI` `SQLAlchemy` `SQLite` `Docker` `NVD API`
